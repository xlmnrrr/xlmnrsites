2. Какие данные обрабатываются

  • Данные из формы заявки: имя; контакт для связи по вашему выбору — номер телефона, адрес электронной почты или ссылка на профиль в соцсети или мессенджере; текст сообщения, если вы его заполнили.
  • Технические данные отправки заявки: адрес страницы и время отправки.
  • IP-адрес и сведения о браузере, которые автоматически получают серверы хостинга Сайта и облачной функции при обращении к ним.
  • Cookie и обезличенная статистика посещений (Яндекс.Метрика) — только если вы нажали «Принять все» или включили аналитику в настройках cookie.

Специальные категории персональных данных и биометрические данные не обрабатываются. Пожалуйста, не указывайте в сообщении сведения, которые не нужны для обсуждения задачи.

Обработка смешанная: с использованием средств автоматизации и без них.

5. Кому и как передаются данные

5.1. Заявка из формы отправляется по защищённому соединению в облачную функцию, размещённую в Yandex Cloud (ООО «Яндекс.Облако», Россия). Функция сразу пересылает заявку Оператору личным сообщением в социальной сети «ВКонтакте» через VK API (ООО «ВК», Россия). Функция не сохраняет заявки; технические журналы работы функции хранятся в Yandex Cloud в пределах установленного срока хранения журналов.

5.2. Если доставка во «ВКонтакте» временно недоступна, заявка может быть направлена на электронную почту Оператора в сервисе Mail.ru (ООО «ВК», Россия).

5.3. Яндекс.Метрика (ООО «Яндекс», Россия) получает данные о посещениях только после вашего согласия на аналитические cookie.

5.4. Статические файлы Сайта размещены на хостинге GitHub Pages (GitHub, Inc., США). При открытии страниц ваш браузер обращается к серверам хостинга, которые автоматически получают IP-адрес и сведения о браузере. Данные из формы заявки на хостинг не передаются.

5.5. Иным лицам данные не передаются, за исключением случаев, предусмотренных законодательством Российской Федерации.

5.6. Запись, систематизация, накопление, хранение, уточнение и извлечение персональных данных граждан Российской Федерации из формы заявки осуществляются с использованием баз данных, находящихся на территории Российской Федерации.
